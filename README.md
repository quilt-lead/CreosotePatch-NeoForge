# CreosotePatch NeoForge

A NeoForge continuation of **CreosotePatch**, originally created by **GoldenEye70**.

## About

CreosotePatch provides compatibility between creosote-treated wood from **Immersive Engineering** and hardened wood from **Create: The Factory Must Grow**.

This project is a separate NeoForge continuation rebuilt for Minecraft 1.21.1.

## Status

Currently in development.

Target:

* Minecraft 1.21.1
* NeoForge 21.1.x
* Java 21

The goal of this project is to provide compatibility between:

* Immersive Engineering creosote-treated planks
* Create: The Factory Must Grow hardened planks
